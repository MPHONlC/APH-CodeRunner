[SIZE="5"][COLOR="SeaGreen"]APH-CodeRunner[/COLOR][/SIZE]
[COLOR="Gray"][i]An in-game Lua code editor and runner.[/i][/COLOR]

[SIZE="3"][COLOR="DarkOrchid"]Dependencies:[/COLOR][/SIZE]

This addon requires:
[LIST]
[*] [COLOR="#FF69B4"]LibAPH[/COLOR] [COLOR="Gray"][i](Required Unified helpers shared with my addons)[/i][/COLOR]
[/LIST]

[SIZE="3"][COLOR="DarkOrchid"]Slash Commands[/COLOR][/SIZE]

[LIST]
[*] [color=#00FFFF]/coderunner[/color]: opens or closes the editor.
[/LIST]

[SIZE="3"][COLOR="DarkOrchid"]Limits[/COLOR][/SIZE]

Only for PC and It runs Lua only, and each edit box can hold up to 29,903 characters. (you can create another edit box with the same .lua name to combine them)
