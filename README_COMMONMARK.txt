# APH-CodeRunner

*An in-game Lua code editor and runner.*

## Dependencies

Requires **LibAPH** (shared helper library, hard dependency).

## Slash Commands

- `/coderunner`: opens or closes the editor.

## Limits

Only for PC and It runs Lua only, and each edit box can hold up to 29,903 characters. (you can create another edit box with the same .lua name to combine them)
